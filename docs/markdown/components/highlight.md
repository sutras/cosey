# Highlight 代码高亮

## 简介

把 [Prism](https://prismjs.com/) 封装成了 vue 组件，简化代码高亮的使用，并内置了复制按钮。

## 代码演示

### 基础使用

使用 `code` 属性设置代码，使用 `lang` 属性设置代码语言。

::: demo

highlight/basic

:::

## API

### HighlightProps

| 属性       | 描述                   | 类型                                                                                                                                                                                                                | 默认值 |
| ---------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| code       | 要高亮的代码内容       | string                                                                                                                                                                                                              | -      |
| lang       | 代码语言               | 'text' \| 'xml' \| 'html' \| 'css' \| 'less' \| 'sass' \| 'scss' \| 'js' \| 'ts' \| 'jsx' \| 'tsx' \| 'json' \| 'json5' \| 'markdown' \| 'bash' \| 'python' \| 'java' \| 'php' \| 'sql' \| 'nginx' \| (string & {}) | 'text' |
| max-height | 设置滚动元素的最大高度 | string                                                                                                                                                                                                              | -      |

### HighlightSlots

| 插槽    | 描述           | 属性 |
| ------- | -------------- | ---- |
| default | 自定义默认内容 | -    |
