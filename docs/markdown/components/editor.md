# Editor 编辑器

## 简介

图片上传依赖于 `launch api.upload` 接口，需要保证接口返回一个文件地址。

表格基于 `prosemirror-tables`，光标进入单元格后表格上方会浮出工具条（点编辑器外面会收起），支持：

- 行/列：上移、下移、左侧/右侧插入、选中行/列插入、删除，以及表格整体删除
- 单元格：框选多个单元格后合并、拆分已合并的单元格；拖拽框选时只高亮单元格，
  不会顺手把文字也选中（在单个单元格内拖拽仍然照常选文字）
- 清除格式：光标在表格里时会作用于**所有选中的单元格**，一次清掉各单元格内容上的加粗、
  斜体、字号、颜色、对齐、缩进等；单元格自身的底色、字色、垂直对齐属于单元格属性，
  请用表格工具条上对应的「清除」按钮处理
- 表头：把选中的行/列/单元格切换成表头（`th`）
- 单元格样式：底色（12 个预设色 + 清除）、文字颜色（单元格级默认字色）、顶端/垂直居中/底端对齐
- 列宽：鼠标移到列边界可直接拖拽，宽度以 `data-colwidth` 存在单元格上，可随 HTML 往返
- 键盘：`Tab` / `Shift-Tab` 切换单元格，方向键在单元格间移动，`Shift-方向键` 框选单元格，
  `Backspace` / `Delete` 清空框选的单元格

合并范围（`colspan`/`rowspan`）、列宽（`data-colwidth`）、底色、字色与垂直对齐都会写进序列化的
HTML，因此 `v-model` 的值可以直接保存并在下次渲染时还原。

### 两种文字颜色的区别

工具条上的「字体颜色」是**行内 mark**（序列化成 `<span style="color">`），只作用于选中的文字；
表格工具条里的「单元格文字颜色」是**单元格属性**（给 `<td>` 加 `color`，内容继承），因此：

- 对空单元格也能生效，之后输入的文字自动带上这个颜色
- 框选多个单元格可以一次性设置，不需要先选中文字
- 两者是叠加关系：单元格字色是默认值，某段文字单独设过字体颜色时以行内 mark 为准

### 浮动工具栏

通过 `toolbar="float"` 切换到浮动工具栏形态，适合空间有限的场景：

- **行内样式工具条**：选中文本、松开鼠标后浮出（拖选过程中不跟随移动），包含常用样式（加粗/斜体/下划线/删除线/行内代码/颜色/背景/链接/清除格式）；末尾的「更多」按钮可展开不常用操作（撤销/重做、字体、字号、上标/下标、缩进、源码模式），覆盖固定工具栏的全部功能。
- **块级菜单入口**：鼠标移入编辑器时，在当前块级元素左侧浮出一个「+」入口按钮，点击后在右侧弹出多级上下文菜单：顶级提供标题（二级子菜单选择层级）、有序/无序列表、引用、代码块等高频块级样式，对齐方式与插入元素（图片/视频/表格/公式）收进二级子菜单；页面或编辑器滚动时，入口按钮与菜单跟随所在块级元素。

## API

### EditorProps

| 属性                  | 描述                                                      | 类型    | 默认值  |
| --------------------- | --------------------------------------------------------- | ------- | ------- |
| model-value (v-model) | 编辑器当前值                                              | string  | -       |
| placeholder           | 编辑器占位文本                                            | string  | -       |
| height                | 编辑器高度                                                | string  | -       |
| max-height            | 编辑器最大高度                                            | string  | -       |
| readonly              | 是否只读                                                  | boolean | false   |
| disabled              | 是否禁用                                                  | boolean | false   |
| toolbar               | 工具栏展示形态，`default` 固定工具栏 / `float` 浮动工具栏 | string  | default |

### EditorEmits

| 事件              | 描述               | 类型                    |
| ----------------- | ------------------ | ----------------------- |
| update:modelValue | 编辑器值改变时触发 | (value: string) => void |
| change            | 编辑器值改变时触发 | (value: string) => void |
