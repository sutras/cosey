   - 新方案：ElPopover + `virtual-ref`（指向「更多」按钮的 Measurable 包装对象）+ `virtual-triggering` + `visible={true}` 受控（外层 `moreVisible && moreAnchor &&` 条件渲染控制存在性），`popperClass={bem.e('more')}`。

   - `isInsideToolbarUi` 补了 `.${bem.e('more')}`（popper teleport 到 body，类名 `co-editor-float-toolbar__more` 不被 `.co-editor-float-toolbar` 覆盖）。
   - SCSS 删除了 `.more` 的 absolute 定位样式块。
   - 关键洞察：ElPopover 受控模式（`visible` 为 boolean 且无 `update:visible` handler）下 `controlled=true`，clickOutside/blur 不会自动关闭——这避开了旧注释里的 focus-trap 误关问题。agent-browser 实测全部通过。

## 关键坑：pnpm store 版本冲突

本机 corepack 默认 pnpm 11.x（store v11），但项目 node_modules 由 pnpm 10.x（store v10）安装，直接 `pnpm install` 会报 `ERR_PNPM_UNEXPECTED_STORE` 或长时间卡住。

**解决**：用 `corepack pnpm@10 <cmd>` 强制走 pnpm v10（store v10 匹配）。例如：

```
corepack pnpm@10 add richtext-icons@0.3.0 --filter cosey
```

## 测试技巧：触发浮动工具条

ProseMirror 编辑器里用 JS 设置 DOM Range 不会更新 `state.selection`（`state.selection.empty` 仍为 true，浮动工具条不出来）。用 agent-browser 的真实事件链：`click 段落` → `press Home` → 连按 `Shift+ArrowRight` 扩选。float demo 编辑器定位：页面 3 个 `.co-editor` 中第 3 个（标题「行内样式工具条」），可临时 `pm.id = 'float-demo-editor'` 再用 `#float-demo-editor p` 选择器。

## BlockMenu 两问题修复（全选 + 表格网格闪动）

1. **全选后入口按钮消失**（`useBlockRect.ts`）：全选时 `selection.$from` 在 doc 顶层（depth 0），`$from.depth < 1` 直接返回 null。修复：depth < 1 时锚定文档第一个块（`state.doc.firstChild`，pos 0，`view.nodeDOM(0)` 返回第一个块的 DOM——nodeDOM 语义是「pos 之后的节点」）。
2. **表格网格关闭闪到左上角**：网格（Picker/ElTooltip）锚定菜单项，选完格子关菜单 → 菜单项 display:none → popper reference 丢失重定位到 (0,0)，而弹窗淡出还没结束 → 先跳左上角再消失（实测闪 2 帧）。
   - 修复组合：① Picker 加 `noTransition` prop + `co-editor-picker-instant` 零时长过渡（scss 定义）；② 关键是 **Picker expose `hide()`**：同步 `popper.style.display = 'none'`（不等 Vue 渲染），`onCellClick` 里先 `pickerRef.hide()` 再 `visible=false` 再 `onTrigger` 关菜单。noTransition 单独用时仍有 1-2 帧窗口期（Vue 更新时序），同步 DOM 隐藏才彻底。
